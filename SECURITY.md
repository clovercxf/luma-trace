# Security

LumaTrace is a local macOS application. Do not report vulnerabilities in public issues if they include exploit details or user data.

Please use GitHub's private vulnerability reporting for this repository when available. Otherwise, contact the repository owner through their GitHub profile and share only the minimum information needed to reproduce the issue. Never send photo libraries, access tokens, passwords, or private keys.

The app is currently distributed as an unsigned, unnotarized local build. Install only builds you have reviewed and obtained from a source you trust.
