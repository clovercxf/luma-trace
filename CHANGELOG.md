# Changelog / 更新日志

LumaTrace release history / LumaTrace 版本记录。

## 0.4.6 — 2026-10-20

### English

- Added a first-launch privacy notice and required consent before entering the library.
- Added a Settings privacy and permissions checklist for monitored folders, camera, and memory notifications.
- Added an explicit macOS folder-access selection step when adding monitored locations; access is limited to folders the user selects.
- Improved first-run guidance and made permission requests contextual to each feature.
- Updated English/Chinese README and user documentation; clarified Clover F copyright and proprietary reuse restrictions.
- Added DMG packaging alongside the ZIP archive.

### 简体中文

- 新增首次启动隐私说明，阅读并同意后才能进入资料库。
- 设置中新增隐私与权限检查，可查看监测文件夹、相机和回忆通知状态。
- 添加监测位置时增加 macOS 文件夹访问授权步骤，权限仅对应用户所选文件夹。
- 改进首次使用引导，并将权限请求放在对应功能使用时触发。
- 更新中英文 README 和用户手册；明确 Clover F 版权归属及专有内容的使用限制。
- 新增 DMG 安装包，同时保留 ZIP 压缩包。

## 0.4.5 — 2026-10-19

### English

- Added the LumaTrace product identity, multilingual interface, local-first library workflows, map browsing, duplicate review, and scheduled memory films.
- Added monitored-folder management, retry tools, video analysis settings, and native-style media preview improvements.

### 简体中文

- 建立 LumaTrace 产品标识和多语言界面，完善本地资料库、地图浏览、重复影像检查和定时回忆短片。
- 增加监测文件夹管理、失败项重试、视频分析设置和原生风格影像预览体验。
